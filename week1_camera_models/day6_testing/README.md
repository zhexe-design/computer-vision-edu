# Day 6 — Calibration Validation & Distance Measurement

Validate camera calibration by measuring **real-world distances** on the chessboard plane.

Uses `solvePnP` + ray–plane intersection to convert pixels → meters.

## Limitation

Measurements are valid only for points that lie in the **same plane** as the chessboard (for example, an object lying flat on the same table).

## What this demonstrates

- Loading calibration (`K`, `dist`) from Day 5
- Pose estimation with `cv2.solvePnP`
- Undistorted ray → intersection with board plane `Z = 0`
- Metric distance between two pixels
- Automatic sanity check vs known square size
